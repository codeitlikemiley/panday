# Commit messages

The diff shows *what* changed. A message earns its place by recording *why*.

## Shape

```
<type>: <summary in the imperative>

<body: the reason, the alternative rejected, the risk>
```

## Rules

1. Say what a reader cannot get from the diff.
2. Name the bug you fixed and how you know it is fixed.
3. If you deviated from a spec, say which spec and why.
